## Supported platforms

What the application expects to find:

Anything from Windows 10 onward is enough to run this. A 64-bit edition of Windows is what this build expects. No separate Visual C++ or .NET runtime install is required; the archive carries what the build needs. Windows releases starting at Windows 10 are the ones that can run this.
